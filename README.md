# Victor Magoto — Personal Profile

A responsive, single-page professional profile focused on forensic accounting, ERP implementation, internal controls and data analytics.

## Deploy to Vercel

Import this repository in Vercel. The included `vercel.json` configures the project as a buildless static deployment served from `dist/`.

For local preview:

```powershell
python -m http.server 4173 --directory dist
```
